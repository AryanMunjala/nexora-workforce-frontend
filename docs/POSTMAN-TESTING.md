# API testing note

Postman tests target the Spring Boot backend, not the React frontend. The backend repository contains the API testing guide and importable collection:
- Backend repo: https://github.com/AryanMunjala/nexora-workforce-backend
- Guide: `docs/POSTMAN-TESTING.md`
- Collection: `postman/Nexora-Workforce-Postman-Collection.json`

Default local API base URL: `http://localhost:8080/api`.
